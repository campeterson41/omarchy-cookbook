# Cam's Omarchy cookbook

Customizations for [Omarchy](https://omarchy.org/), one problem per recipe. Each recipe says what stock Omarchy does, why, the change, how to check it, and how to undo it.

Most recipes fit any Omarchy machine. The recipe data at the end of each one says whether it needs particular hardware, what it touches, and which Omarchy version it was tested on.

To follow this cookbook, ask your agent to set you up with [omarchy-kitchen](https://github.com/duff/omarchy-kitchen) and follow `campeterson41/omarchy-cookbook`.
